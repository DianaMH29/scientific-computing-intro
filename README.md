# Intro to Scientific Computing

This repository compiles materials related to the course **Introduction to Scientific Computing**.  
It is designed as a resource hub for students and collaborators, providing examples, exercises, and solutions that support the learning process.

## Contents
- **Sample Codes**: Proposed during lectures and tutorials  
- **Assignments**: Problem sets and coursework  
- **Solutions**: Computational approaches and worked examples  
- **Practices**: Hands-on exercises and experiments  

## Purpose
The goal of this repository is to provide a structured collection of resources that support:
- Programming techniques for scientific applications  
- Numerical methods and algorithms  
- Applied problem-solving in computational science
